# Image placeholders

The MegaMart landing page uses labelled CSS placeholders so the layout works before the product photos are ready. Put your image files in this folder and replace each placeholder in `index.html` with an `<img>` that points to the matching asset.

Suggested filenames:

- `smartwatch-hero.jpg`
- `phone-galaxy.jpg`, `phone-m13.jpg`, `phone-redmi.jpg`, `phone-iphone.jpg`, `phone-pixel.jpg`
- `category-phones.jpg`, `category-computers.jpg`, `category-accessories.jpg`, `category-home.jpg`, `category-watches.jpg`, `category-essentials.jpg`, `category-audio.jpg`
- `brand-apple.jpg`, `brand-realme.jpg`, `brand-xiaomi.jpg`
- `essential-vegetables.jpg`, `essential-greens.jpg`, `essential-strawberries.jpg`, `essential-apples.jpg`, `essential-mangoes.jpg`, `essential-cherries.jpg`

Use descriptive alternative text and consistent image crops. Product tiles are designed around portrait photos; category images work best as square crops.
